Dragging a node in the Studio graph magnetically snaps it to the layer bands.

- Vertical position snaps to the nearest band row while dragging.
- The target band highlights.
- Dropping files the note under that layer.
- Horizontal movement stays free, so nodes can be arranged inside a band.
